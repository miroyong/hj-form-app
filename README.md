# hj-form-app

Página web simples para agilizar o preenchimento do **Relatório Diário de Testemunho — HJ Team** (Google Forms).

## Como usar

1. Acesse a página publicada (GitHub Pages).
2. Escolha o tipo de registro: **🆕 Novo Convidado** ou **🔄 Atualização de Convidado**.
3. Preencha os campos e clique em **Enviar para o Google Form**.
4. Os registros ficam salvos no navegador (localStorage) — busque, exporte em CSV ou recarregue um registro anterior.

## Observações

- É necessário estar logado no Google no navegador para o envio ser registrado no formulário.
- Perguntas de upload de arquivo (ficha PDF + foto) não são enviadas pela página; use a opção **"Abrir no Google pré-preenchido"** para concluir no formulário original.
- A lista de opções foi reduzida para o escopo da equipe Teófilo Otoni.

Feito com a estrutura extraída do formulário (entry IDs) via CDP.
